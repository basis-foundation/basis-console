Decision Simulator

Construct a realistic authorization request — a subject, an action verb, a resource type, and a local resource ID — and preview the normalized request shape. When configured, you can optionally submit it to basis-gateway for a live decision. The gateway composes the canonical action and resource identifier; the console only submits the normalized request and displays the gateway's response. This is an educational, operator-facing builder, not an enforcement path: the console never decides.

Where evaluation happens

Evaluation belongs to basis-core, reached only through basis-gateway. In gateway-evaluation mode the console submits this request to the gateway's authenticated /v1/evaluate endpoint and displays the decision it returns. The gateway authenticates the caller, derives the subject from the verified token, and assembles the audit record. The console never evaluates the request itself and never calls basis-core directly:

Operator → basis-console → basis-gateway → basis-core
