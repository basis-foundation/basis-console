BASIS Console

Status: running

This is the human-facing operational interface for the BASIS ecosystem. It provides read-only visibility into policy state, authorization decisions, and audit activity.

Policies

Review the policies the system reports as loaded. Read-only.

Simulate

Explore the decision-request shape: subject, resource, action.

Audit

Read recent decision outcomes and audit records. Read-only.

What this console is not

The console does not evaluate authorization decisions, authenticate users, normalize protocols, or produce audit records. Those responsibilities belong to basis-core, basis-gateway, and basis-adapters. In production the console reaches the system only through the gateway.
