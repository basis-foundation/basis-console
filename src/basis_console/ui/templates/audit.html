Why correlation IDs matter

A correlation ID connects a single request across the system: the original request, the gateway response, the recorded audit evidence, and operator troubleshooting. The gateway generates it and returns it on the X-Correlation-ID response header. The console never fabricates correlation IDs — the sample events above carry clearly-sample IDs, and live IDs come from the gateway.
